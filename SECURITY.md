# Security Policy

If you discover a security vulnerability in FerrisCore, please report it
responsibly.

**Do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately through
[GitHub Security Advisories](https://github.com/OpenFerris/FerrisCore/security/advisories/new).
If advisories are unavailable, email the maintainer at
<holasoybarbiequetal1090@gmail.com> with `[SECURITY]` in the subject.

Include the following information:

- Description of the vulnerability
- Steps to reproduce
- Affected version or commit
- Potential impact and any suggested fix

Vulnerabilities in the product layer (Desk, server, CLI, WASM host) belong in
[`FerrisFramework`](https://github.com/OpenFerris/FerrisFramework/security/advisories/new).
